# Coupon‑Voucher & Voucher‑Coupon Control System

This document explains how the Coupon‑Voucher system is built, how Admin controls it, and what Businesses see.

---

## 1. What This System Is
This system creates controlled spending power.
It lets customers feel like they have discounts and cashback, while businesses do not lose real money.

It uses two reward types:
- Coupon Voucher (creates value)
- Voucher Coupon (controls where value can be spent)

All rewards live under one place called **Deals**.

---

## 2. How the Coupon‑Voucher Is Created

Admin creates a reward with:
- A name (example: £100 Spring Coupon Voucher)
- A total value (example: £100)
- A split (example: 50% customer, 50% reward)
- Where it can be used (any shop, certain shops, or expo only)
- How cashback can be added

The system stores:
- How much is real money
- How much is reward money
- How much can be topped up

Users only see the total value.

---

## 3. Admin Dashboard Controls

Admin can:
- Create new Coupon Vouchers
- Set 50/50, 70/30 or 80/20 splits
- Decide which businesses can add cashback
- Set cashback limits by membership level (Pro, Pro Plus, Platinum)
- Decide where vouchers can be spent
- Turn campaigns on or off
- Set seasonal labels (Spring, Summer, Expo)

Admin can see:
- How many vouchers were created
- How much real money entered
- How much reward value was given
- How much was spent
- Which businesses benefited

Admin also sees "actual increase" showing if sales went up or not.

---

## 4. Business Dashboard View

Businesses do not create the voucher type.
They only interact with what Admin allows.

They see:
- Active Coupon Vouchers
- How much cashback they can offer
- How many customers used them
- How much value was spent in their shop

They can:
- Attach Coupon Vouchers to campaigns
- Give £2, £3 or £5 cashback into a customer’s voucher
- See how it increased their sales

They never give real money.
They only give reward value.

---

## 5. Customer Flow (What It Looks Like)

Customer sees:
- “£100 Coupon Voucher”

They may:
- Pay £50
- Or receive £50 from family

Voucher now shows £100 to spend.

They go to a shop.
Shop adds cashback using Coupon Voucher.
Voucher balance increases.

Customer keeps spending until balance is zero.

---

## 6. Why This System Works

Because:
- Money never leaves the network
- All rewards turn into spending
- Businesses do not give discounts
- Customers feel rewarded

This is the core growth engine of 247GBS, MCOM and the Expo.
